# אוטומציה: Timeless ← טיוטה לאישורך

כשמגיע מ-Timeless מייל עם סיכום פגישה, הסקריפט:
1. מחלץ את שם הפגישה ואת הסיכום המלא (כותרות, סעיפים, משימות לביצוע).
2. יוצר קובץ **Word (DOCX)** בעברית, מימין לשמאל, בגופן David, עם הכיתוב "טיוטה לאישורך" בראש המסמך.
3. שולח אותו במייל ל-`sigal@sigalaw.co.il` עם הנדון:
   **`<שם הפגישה> – טיוטה לאישורך`**
4. מסמן את המייל המקורי בתווית `Timeless/נשלח כטיוטה` כדי שלא יישלח שוב.

הסקריפט רץ אוטומטית כל 10 דקות.

## התקנה חד-פעמית (כ-5 דקות)
1. נכנסים ל-https://script.google.com עם החשבון **sigal@sigalaw.co.il** ← **New project**.
2. מוחקים את התוכן ומדביקים את כל הקוד מ-`Code.gs`.
3. ⚙️ **Project Settings** ← מסמנים *Show "appsscript.json" manifest file in editor*,
   חוזרים לעורך ומחליפים את תוכן `appsscript.json` בתוכן הקובץ שכאן.
4. שומרים (Ctrl+S), נותנים לפרויקט שם, למשל `Timeless לטיוטה`.
5. בוחרים בפונקציה **`testOnLatest`** ← **Run** ← מאשרים הרשאות.
   אמור להגיע מייל עם הטיוטה של הפגישה האחרונה. כך בודקים שהקובץ נראה טוב.
6. בוחרים בפונקציה **`installTrigger`** ← **Run**. מעכשיו זה רץ לבד.

## שינויים
כל ההגדרות נמצאות בראש `Code.gs` באובייקט `CONFIG`: נמען, סיומת הנדון, גופן ועוד.

## חשוב לדעת
- Timeless שולח שני סוגי מיילים. רק המייל **"... shared meeting notes with you"** מכיל
  את הסיכום עצמו. המייל "Your meeting insights" מכיל רק קישור, ולכן לא מטופל.
  כדי שתגיע טיוטה, צריך לשתף את חדר הפגישה (Share) לכתובת `sigal@sigalaw.co.il`,
  או להגדיר ב-Timeless שיתוף אוטומטי של הסיכום במייל.
- מה שנשלח הוא **הסיכום** ש-Timeless מפיק, לא התמלול המילולי המלא.
- קובץ הביניים ב-Google Drive נמחק מיד לאחר יצירת ה-DOCX.
- תקלות אפשר לראות ב-Apps Script תחת **Executions**.
